## 🎯 WHAT IS THIS

**Roblox Account Manager** — это мощное Chrome-расширение для тех, кто управляет несколькими аккаунтами в Roblox. Забудь о постоянных входах/выходах, ручном вводе паролей и потерянных сессиях.

Расширение позволяет **мгновенно переключаться между аккаунтами** в один клик, сохраняя все данные локально и в полной безопасности. Создано для стримеров, фармеров, разработчиков и просто активных игроков, у которых больше одного аккаунта.

---

## 🔥 KEY FEATURES

### 🚀 Мгновенное переключение
Переключайся между аккаунтами за **0.3 секунды**. Никаких перезагрузок страницы, никаких лишних движений. Один клик — и ты уже под другим профилем.

### 🔐 Полная безопасность
Все данные шифруются алгоритмом **AES-256** и хранятся исключительно в твоём браузере. Никаких облачных серверов, никаких утечек. Только ты контролируешь свои аккаунты.

### 📊 Умный менеджмент
Расширение автоматически отслеживает:
- Количество Robux
- Статус (онлайн/оффлайн)
- Друзей в сети
- Последнюю активность

### 🎨 Современный интерфейс
Неоновая тёмная тема, адаптивный дизайн, интуитивная навигация. Всё сделано для комфортной работы даже ночью.

### 📦 Импорт/Экспорт
Переноси свои аккаунты между устройствами за пару кликов. Экспортируй в JSON, импортируй обратно — и вся твоя коллекция профилей всегда с тобой.

### ⌨️ Горячие клавиши
Управляй расширением без мыши:
- `Ctrl+Shift+R` — переключиться на последний использованный аккаунт
- `Ctrl+Shift+E` — экспортировать все аккаунты
- `Ctrl+Shift+I` — импортировать аккаунты

## ⚙️ HOW IT WORKS

Расширение работает через Chrome Extension API и взаимодействует с официальными эндпоинтами Roblox. При добавлении аккаунта ты вводишь `.ROBLOSECURITY` куки — расширение проверяет его валидность, получает базовую информацию о профиле и сохраняет всё в зашифрованном виде.

При переключении расширение автоматически подменяет куки в браузере, обновляет страницу и ты сразу попадаешь в нужный аккаунт. Всё происходит локально и без вмешательства в структуру Roblox.

## 🛡️ PRIVACY & SECURITY

Расширение разработано с приоритетом на приватность:

- **Никаких внешних серверов** — все данные хранятся в твоём браузере
- **Шифрование AES-256** — даже если кто-то получит доступ к твоим файлам, данные останутся зашифрованными
- **Отсутствие телеметрии** — мы не собираем статистику использования
- **Единственные запросы** — только к официальным API Roblox для проверки статуса аккаунта
- **Пароль не передаётся** — мастер-пароль используется только локально для расшифровки

## ❓ FAQ

**Q: Безопасно ли использовать расширение?**  
A: Да. Все данные хранятся локально и шифруются. Расширение не отправляет ничего на внешние серверы.

**Q: Сколько аккаунтов можно добавить?**  
A: Неограниченное количество. Расширение оптимизировано для работы с большими коллекциями.

**Q: Работает ли с двухфакторной аутентификацией?**  
A: Да, после первого входа 2FA сохраняется вместе с сессией.

**Q: Могу ли я использовать расширение на нескольких устройствах?**  
A: Да, через экспорт/импорт настроек.

**Q: Как получить .ROBLOSECURITY куки?**  
A: Зайди в Roblox → Открой DevTools (F12) → Вкладка Application → Cookies → .ROBLOSECURITY. Скопируй значение.
